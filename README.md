Library Management System (C++)

## Project Overview

The **Library Management System** is a console-based application developed using **C++** that helps manage library records efficiently.
The system allows users to add, search, issue, and return books while maintaining records using **file handling and data structures**.

This project demonstrates the use of **basic Data Structures, file handling, and object-oriented programming concepts** in C++.

## Features

* Add new books to the library
* Display all available books
* Search books by ID or title
* Issue books to users
* Return issued books
* Maintain book records using file handling
* Simple and user-friendly console interface

## Technologies Used

* **C++**
* **Data Structures**
* **File Handling**
* **Object-Oriented Programming**
* **Standard Template Library (STL)**



## System Workflow

1. User runs the program.
2. The system displays a menu with different options.
3. User can:

   * Add a new book
   * View available books
   * Search for a book
   * Issue a book
   * Return a book
4. Book records are stored and managed efficiently.
